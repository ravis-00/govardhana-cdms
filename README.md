# Govardhana CDMS

Govardhana CDMS is a Cattle and Dairy Management System developed for Madhava Srusti Rashtrotthana Goshala.

The application supports cattle lifecycle management, veterinary care, dairy operations, feeding, waste management, sponsorships, administration and operational reporting.

## Technology Stack

- React
- Vite
- JavaScript
- Google Apps Script backend
- Google Sheets database
- Netlify frontend hosting
- Cloudinary image storage
